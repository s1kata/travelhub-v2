# QA — Блок 3: чартер и прямой рейс (сайт)

**Дата:** 2026-08-26  
**Среда:** test / prod после деплоя  
**Для:** Даник  
**Что сделали:** в фильтрах поиска — галочки **«Только чартер»** и **«Прямой рейс»**. Они уходят в API Tourvisor.

---

## Как проверить

### 0. Подготовка
1. Ctrl+F5 на главной после деплоя.
2. Открыть **Фильтры** в форме поиска (кнопка «Фильтры»).

**Ожидание:**
- [ ] Видны две галочки: **Только чартер**, **Прямой рейс**.

### 1. Обычный поиск (без галочек)
1. Москва → **Вьетнам** (или Таиланд), даты, ночи → Найти.

**Ожидание:**
- [ ] Есть выдача (туры/отели).
- [ ] Бейдж «Прямой рейс» на карточках **не** обязателен.

### 2. Только прямой рейс
1. Те же параметры, включить **«Прямой рейс»** → Найти (или галочку после выдачи — поиск перезапустится).

**Ожидание:**
- [ ] Выдача меняется / сужается (или empty, если прямых нет на даты).
- [ ] На карточках туров может быть бейдж прямого рейса.
- [ ] Нет бесконечного лоадера / JS-ошибки в консоли.

### 3. Только чартер
1. Снять «Прямой», включить **«Только чартер»** → Найти.
2. Страна лучше **Турция** или **Египет**.

**Ожидание:**
- [ ] Поиск отрабатывает.
- [ ] Выдача выглядит как чартерные пакеты (не обязательно проверять каждый рейс вручную).

### 4. Обе галочки
1. Турция / Египет, обе галочки вкл → Найти.

**Ожидание:**
- [ ] Поиск не падает.
- [ ] Либо есть туры, либо понятный empty state.

### 5. Мобилка
1. 390px: открыть Фильтры.

**Ожидание:**
- [ ] Галочки кликабельны, текст не обрезан.

**шаги → URL → ПК/моб → галочки (чартер/прямой) → ожидал → увидел → скрин**

## Не в этом блоке (не баг)
- Подсветка дат/ночей в календаре под прямые — следующий блок / отдельно.
- Пустая выдача при «Прямой» на слабые даты — нормально.
