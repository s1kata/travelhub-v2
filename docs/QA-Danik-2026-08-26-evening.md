## Блок A — Режим «Отели» (без перелёта)

**Суть:** в режиме Отели поиск идёт с вылетом **«Без перелёта»** (`departureId=99`). Цены — **только проживание**, без авиа.

### A1. Переключение режима
1. На главной вкладки: **Туры** / **Отели**.
2. Включить **Отели**.

**Ожидание:**
- [ ] Подсказка вроде: «Цены только за проживание — без перелёта».
- [ ] Поле «Откуда» заблокировано / показывает без перелёта (нельзя выбрать Самару как для туров).
- [ ] Переключить обратно на **Туры** — снова обычный город вылета (Самара/Москва).

### A2. Поиск отелей
1. Режим **Отели**.
2. Страна: Египет / Турция / Таиланд (что удобно).
3. Даты + ночи + «Найти».

**Ожидание:**
- [ ] Есть выдача.
- [ ] Над/у результатов текст: цены **без перелёта / только проживание**.
- [ ] На карточке подпись цены: **«проживание от …»** (не «за двоих с перелётом»).
- [ ] Блок рейсов на карточке **не** грузится / скрыт.

### A3. Карточка отеля
1. Открыть отель из выдачи режима Отели.

**Ожидание:**
- [ ] Страница открывается, цены выглядят как проживание (логично ниже, чем тур с авиа — ориентир, не точная математика).
- [ ] В адресе/параметрах может быть `departureId=99`.

### A4. Туры не сломались
1. Режим **Туры**, вылет Самара или Москва.
2. Та же страна → «Найти».

**Ожидание:**
- [ ] Обычный поиск туров, цена «за N» как раньше.
- [ ] Рейсы на карточке могут появляться (если были).

## Блок B — Скорость поиска (progressive)

**Суть:** если кэша нет, выдача может появиться **раньше**, чем 100% прогресса (early paint), потом обновиться.

### B1. Обычный поиск
1. Режим **Туры**, страна + даты + ночи → **Найти**.
2. Смотреть: лоадер → карточки.

**Ожидание:**
- [ ] Либо мгновенно из кэша, либо через несколько секунд появляются карточки (не «тишина» 20+ сек).
- [ ] Постфильтры (бюджет/звёзды и т.д.) работают после выдачи.
- [ ] Нет вечной крутилки / пустого экрана при живом ответе.

### B2. Сдвиг дат ±3 / ±6
1. После выдачи нажать сдвиг дат (±3 или ±6), если кнопки есть.

**Ожидание:**
- [ ] Выдача обновляется без полного краша.
- [ ] Можно снова фильтровать результаты.

## Блок C — Модалка «Сколько ночей?»

1. Выбрать страну + даты.
2. Открыть **Ночи**.

**Ожидание:**
- [ ] Сверху понятно **От — До** (не сырой текст).
- [ ] Быстрые чипы (7, 7–10…) подсвечивают диапазон в сетке (ячейки между от и до).
- [ ] При выборе «от», потом наведении/выборе «до» — диапазон виден.
- [ ] Легенда «Есть туры / Прямой» — если данные подгрузились (1–3 сек); если кэш пуст и меток нет — не стоп-баг, выбор ночей должен работать.
- [ ] **Применить** сохраняет диапазон в строке поиска.
- [ ] Мобилка: модалка снизу, кнопка Применить доступна, сетка читаемая.

- [ ] Подсветка дней с вылетами (если есть) — полоска/фон.
