# QA — Блок 5: смена пакета перелёта (карточка тура)

**Дата:** 2026-08-26  
**Среда:** test / prod после деплоя  
**Для:** Даник  
**Что сделали:** на карточке тура — блок **«Варианты перелёта»**: список пакетов из Tourvisor, выбор меняет цену; выбранный рейс уходит в заявку менеджеру.

---

## Как проверить

### 0. Подготовка
1. Ctrl+F5 после деплоя.
2. Поиск: Москва → **Турция** / **Вьетнам** / **Таиланд**, даты, ночи → Найти.
3. Открыть **любой тур** (карточка / «Подробнее»).

### 1. Блок вариантов
**Ожидание:**
- [ ] Под чипами есть секция **«Варианты перелёта»**.
- [ ] Виден хотя бы один вариант (туда / обратно, авиакомпания).
- [ ] У вариантов может быть цена справа и бейджи «Прямой» / «С пересадкой».
- [ ] Один вариант выбран (подсветка / radio).

### 2. Смена пакета → цена
1. Если вариантов **больше одного** — выбрать другой.

**Ожидание:**
- [ ] Подсветка переходит на новый вариант.
- [ ] Чип «Перелёт» сверху обновляется (рейсы / авиакомпания).
- [ ] Цена в сайдбаре / у кнопки **меняется** (если у пакетов разные цены).
- [ ] На акциях (`from_promo`) цена может **не** перебиваться — это ок.

### 3. Один вариант
1. Тур, где API отдал только 1 пакет.

**Ожидание:**
- [ ] Блок всё равно виден с одним вариантом.
- [ ] Нет ошибки / пустого «уточните у менеджера», если рейсы пришли.

### 4. Заявка менеджеру
1. Выбрать пакет (если есть выбор) → «Заявка» / без оплаты → отправить тестовую.

**Ожидание:**
- [ ] В заявке / примечании CRM есть строка про **перелёт (выбранный пакет)** и **актуальная цена**.

### 5. Мобилка
1. 390px: блок вариантов.

**Ожидание:**
- [ ] Карточки читаются, radio удобно нажать, цена не обрезается критично.

---

## Куда писать баг

**шаги → тур (ссылка) → сколько вариантов → сменил на какой → ожидал цену X → увидел Y → скрин**

## Не баг
- Нет блока, если Tourvisor не отдал flights (остаётся заглушка «уточните у менеджера»).
- Один вариант без смены — норма.
- Это **пакет тура**, не отдельный билет Aviasales.
