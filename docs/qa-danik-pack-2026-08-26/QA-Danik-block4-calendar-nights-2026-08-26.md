# QA — Блок 4: подсветка дат и ночей (прямые / чартер)

**Дата:** 2026-08-26  
**Среда:** test / prod после деплоя  
**Для:** Даник  
**Что сделали:** в календаре дат и в сетке ночей подсвечиваются варианты с вылетами; при галочке **«Прямой рейс»** / **«Только чартер»** остальные приглушаются.

---

## Как проверить

### 0. Подготовка
1. Ctrl+F5 после деплоя.
2. Вылет **Москва**, страна **Вьетнам** или **Таиланд**.
3. Открыть **Фильтры** — галочки чартер / прямой на месте.

### 1. Календарь без галочек
1. Открыть **Даты вылета**.

**Ожидание:**
- [ ] Часть дней с подсветкой (синяя полоска / фон) — есть вылеты.
- [ ] Дни без вылетов выглядят обычными / бледнее.

### 2. Календарь + «Прямой рейс»
1. Включить **Прямой рейс**.
2. Снова открыть календарь.

**Ожидание:**
- [ ] Даты с прямыми заметнее (фон/полоска).
- [ ] Остальные даты с вылетами приглушены (если API отдал отдельный список прямых).
- [ ] Если подсветка прямых не отличается от обычной — не баг критичный (API мог не отфильтровать); главное — поиск с галочкой из блока 3 работает.

### 3. Ночи
1. Выбрать диапазон дат.
2. Открыть **Ночей**.

**Ожидание:**
- [ ] Часть чисел (7, 10, 11…) может быть обведена / с фоном — «есть в кэше/выдаче».
- [ ] При **Прямой рейс** / **Чартер** числа вне доступных — бледнее.
- [ ] Если обводок нет (кэш пуст) — не стоп-баг; выбор ночей всё равно работает.

### 4. Смена страны / вылета
1. Сменить страну на Турцию → открыть календарь.
2. Сменить вылет Самара → календарь.

**Ожидание:**
- [ ] Подсветка обновляется (не «залипает» старая страна).

### 5. Мобилка
1. 390px: календарь и ночи.

**Ожидание:**
- [ ] Подсветка видна, попапы не ломаются.

---

## Куда писать баг

**шаги → страна/вылет → галочки → календарь или ночи → ожидал → увидел → скрин**

## Не баг
- Нет цен «от Xк» на дне — это отдельная карта цен, не блок 4.
- Пустая выдача при жёстких галочках.
