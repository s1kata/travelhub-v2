# QA — Блок 2: полный список стран (сайт)

**Дата:** 2026-08-26  
**Среда:** test / prod после деплоя  
**Для:** Даник  
**Что сделали:** в поиске «Куда» — полный список стран из Tourvisor (не 4 штуки). Страны грузятся **с городом вылета**.

---

## Как проверить

### 1. Главная → страна
1. Открыть главную, Ctrl+F5 (сброс кэша).
2. Открыть выбор страны («Куда» / попап стран).

**Ожидание:**
- [ ] Стран **много** (примерно 40–60+), не только Турция / Египет / Абхазия / Россия.
- [ ] Есть **Вьетнам**, **Шри-Ланка**, **Таиланд**, **ОАЭ**.
- [ ] Можно найти страну через поиск в попапе (если есть поле поиска).

### 2. Смена города вылета
1. Выбрать вылет **Москва** → открыть список стран (запомнить, что Вьетнам/Шри-Ланка есть).
2. Выбрать вылет **Самара** → снова открыть страны.

**Ожидание:**
- [ ] Список стран **обновляется** под город вылета.
- [ ] Если страна осталась доступна — выбор не сбрасывается зря.
- [ ] Можно выбрать Вьетнам/Таиланд и запустить поиск без ошибки «нет стран».

### 3. Поиск с новой страной
1. Вылет Москва (или Самара).
2. Страна: **Вьетнам** или **Шри-Ланка**.
3. Даты + ночи → Найти.

**Ожидание:**
- [ ] Поиск стартует (лоадер / выдача / понятный empty — не зависание).
- [ ] Нет алерта «страна не найдена».

### 4. Мобилка
1. 390px / телефон.

**Ожидание:**
- [ ] Попап стран скроллится, длинный список не ломает экран.
