# QA — Блок 1: цены на отели (сайт)

**Дата:** 2026-08-26  
**Среда:** test / prod после деплоя  
**Для:** Даник  
**Что сделали:** на карточке отеля показываем **минимальную цену тура** и подпись **«туры от»** (режим «Отели»).

---

## Как проверить (просто)

### 1. Поиск → Отели
1. Открыть главную сайта.
2. Переключить вкладку **«Отели»** (рядом с «Туры»).
3. Выбрать: город вылета, страну (например Турция или Таиланд), даты, ночи.
4. Нажать поиск.

**Ожидание:**
- [ ] У каждой карточки есть цена (не «—» / не пусто), если туры нашлись.
- [ ] Над ценой подпись **«туры от»** (не «за 2 взрослых»).
- [ ] На карточке **нет** блока перелёта (рейсы).
- [ ] Клик по карточке → страница отеля (`tv-hotel-detail`), не сразу тур.

### 2. Цена = минимум
1. Открыть любой отель из выдачи режима «Отели».
2. Посмотреть sticky / блок «Туры от …».
3. Сравнить с ценой на карточке в выдаче.

**Ожидание:**
- [ ] Цена на карточке ≈ минимальной среди предложений на странице отеля (допуск: округление / другой вылет-окно ок, но не «в 2 раза дороже без причины»).

### 3. Режим «Туры» (контроль, ничего не ломаем)
1. Вкладка **«Туры»** → тот же поиск.
2. Карточки туров.

**Ожидание:**
- [ ] Цена есть.
- [ ] Подпись по составу (**«за N взрослых…»**), не обязательно «туры от».
- [ ] Блок перелёта на карточке может быть (как раньше).

### 4. Популярные отели
1. Открыть `/frontend/window/popular-hotels.php`.

**Ожидание:**
- [ ] Карточки с **«туры от»** и ценой (как раньше).

### 5. Мобилка
1. DevTools → iPhone / 390px или реальный телефон.

**Ожидание:**
- [ ] Цена и «туры от» читаются, не обрезаны.
- [ ] Нет горизонтального скролла из‑за цены.

## Куда писать баг

Формат: **шаги → URL → экран (ПК/моб) → что ожидал → что увидел → скрин**.

---

## Не баг (на этот блок)

- Нет цены, если API реально не вернул туры с ценой (пустая выдача / empty state).
- Разные даты на карточке и в деталке, если подгрузились другие окна дат — ок, смотрим **мин. цену**.
