## Чеклист для Даника (полный тест)

### 0. Подготовка
- [ ] Chrome (desktop) + Chrome DevTools mobile (iPhone / 390×844)
- [ ] Инкогнито + обычная сессия (с куками)
- [ ] Тестовый аккаунт (логин/пароль) — если нет, создать через регистрацию
- [ ] Запись: Notion/таблица: баг = шаги + URL + device + severity + скрин

### 1. Главная `/frontend/index.php`
- [ ] Hero грузится, нет огромного CLS / прыжка вёрстки
- [ ] Поиск (wizard / coral search): город вылета, страна, даты, ночи, туристы
- [ ] «Найти» → уходит в результаты / показывает лоадер / ошибку понятно
- [ ] Блок горящих/акционных туров: карточки с ценой, фото, клик → `tour-detail`
- [ ] Блок отелей / VIP / календарь дат — ссылки живые
- [ ] Офисы Самара/Москва — клик ок
- [ ] Чат поддержки / виджеты не перекрывают CTA на мобилке
- [ ] Cookie consent появляется и закрывается
- [ ] Адаптив: нет горизонтального скролла всей страницы

### 2. Поиск и результаты
- [ ] Смена города вылета (Самара / Москва) меняет выдачу
- [ ] Даты: нельзя выбрать прошлые; диапазон валидный
- [ ] Ночи / взрослые / дети с возрастом
- [ ] Пустая выдача: понятный empty state + кнопка изменить параметры
- [ ] Фильтры после выдачи (если есть): питание, звёзды, цена — не ломают список
- [ ] Цена «от … ₽ за тур» не выглядит как «за ночь»
- [ ] Мобилка: sticky-кнопки не перекрывают таббар/чат

### 3. Карточка тура `tour-detail.php`
- [ ] Открыть тур с главной (акция) и из поиска
- [ ] Фото / название / страна / даты / ночи / питание / цена
- [ ] CTA «Оставить заявку» / бронь — модалка открывается
- [ ] Валидация формы: телефон, имя, email
- [ ] Успешная заявка: success-сообщение (без реального списания на test — уточнить)
- [ ] Кнопка «назад» / хлебные крошки не ведут в 404

### 4. Отели
- [ ] `/frontend/window/popular-hotels.php`
- [ ] Фильтр по стране (`?country=4` Турция, `1` Египет, `9` ОАЭ)
- [ ] Карточка отеля → деталка (`hotels/…` или tour)
- [ ] VIP Турция `/frontend/window/turkey-vip-hotels.php`

### 5. Страны и контент
- [ ] `/frontend/window/countries.php` и `countries-list.php`
- [ ] Турция / Египет лендинги
- [ ] Акции `/promotions.php`
- [ ] Календарь выгодных дат `/tour-calendar.php` — даты кликабельны, цены адекватны
- [ ] Услуги / О нас / Видео-туториалы / Для операторов

### 6. Офисы и контакты
- [ ] `/frontend/window/offices.php`
- [ ] Самара / Москва карточки офисов
- [ ] Contacts, реквизиты банка
- [ ] Форма лида с офиса (если есть) — отправка

### 7. Auth / кабинет
- [ ] Регистрация (`registration.php` / desktop)
- [ ] Вход (`login.php`)
- [ ] Забыли пароль
- [ ] Профиль: личные данные, паспорт
- [ ] Выход
- [ ] Гость не видит чужие данные

### 8. Юридическое
- [ ] Privacy / Terms / Consent открываются, читабельны на мобилке

### 9. Кросс-браузер / устройства
- [ ] Desktop Chrome
- [ ] Mobile Chrome Android **или** iPhone Safari
- [ ] Узкий экран 360–390 px: поиск, карточки, модалки

### 10. Перф / SEO (быстро)
- [ ] Главная: нет вечной «крутилки» горящих туров
- [ ] Canonical / og:url не с `http://` и не с `/frontend/frontend/`
- [ ] Favicon есть
- [ ] Console: нет красных ошибок на главной и на search submit
